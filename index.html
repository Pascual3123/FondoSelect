Agregar repositorio de GitHub

Pega la URL de un repositorio público que contenga imágenes. Ejemplo: https://github.com/usuario/wallpapers

En esta versión, las fuentes añadidas se guardan solo en este navegador. Para que sean compartidas entre usuarios y moderadas, conectaremos Supabase y validación en servidor.
